Cookie Clicker AI
An experimental AI agent that learns to play Cookie Clicker using reinforcement learning.
The project explores how an AI can interact with a browser-based game, make decisions, and improve its strategy through repeated training.
🚀 Features
• Automated cookie clicking.
• Purchasing available upgrades.
• Decision-making using a neural network.
• Reinforcement learning with rewards based on progress.
• Saving and loading trained model weights.
• Automated interaction with the game through Python.
